# كلود بعد مرحلة المبتدئ — نص الملقّن
> كل عنوان = شريحة بنفس الترتيب (p-01 … p-15). أقسام «🎬 ديمو» = شريحة ديمو: اضغط S للشاشة، أو وقّف التسجيل وسجّل الديمو بروحه.

## شريحة العنوان
إذا تستخدم كلود مثل گوگل — تسأل، تاخذ جواب، تسكر — فانت مستخدم عشرة بالمية منه.

• هالكورس مو للمبتدئين

• خمس طبقات: مشروع ← أداة ← سكل ← موصلات ← وكيل

• كل قسم بيه شي تطبقه اليوم

### شريحة 1.1 — النافذة
كلود ما يتذكر. كلود يقرا — المحادثة كلها، كل مرة.

• نافذة السياق = الطاولة اللي يشوفها

• المحادثة الطويلة تغطي تعليماتك الأولى

• موضوع جديد = محادثة جديدة

• عدّل رسالتك بدل «لا مو هيچ» — التصحيح يخلي الغلط على الطاولة

### شريحة 1.2 — 🎬 ديمو: ملخص التسليم
⏱ 30 ث · جاهز: محادثة طويلة مفتوحة

① بالمحادثة الطويلة اكتب: «لخّص لي القرارات والنتيجة النهائية بنقاط، حتى أبدي فيها محادثة جديدة»

② انسخ الملخص

③ افتح محادثة جديدة والصقه

④ گول: «هسه بدينا نظيف — وكلود يعرف كل شي مهم»

### شريحة 2.1 — البرومبت المبني
البرومبت الزين مو الأطول — هو اللي ما يخلي كلود يخمّن.

• سياق ← مهمة ← قيود ← شكل ← مثال

• گول «ليش» ويّا كل قاعدة

• افصل البيانات بالوسوم <article>

• المثال يغلب الوصف — الصق بوستاتك

• «اسألني 5 أسئلة قبل ما تكتب»

• التفكير المطوّل للمسائل الصعبة

• اطلب انتقاد مو مديح

### شريحة 2.2 — 🎬 ديمو: قبل / بعد
⏱ 90 ث · جاهز: البرومبت المبني منسوخ — لا تكتبه قدام الكاميرا

① محادثة جديدة: «اكتب لي بوست عن الإنتاجية» ← خلّيهم يشوفون الجواب العام

② محادثة ثانية: الصق البرومبت المبني

③ جاوب على أسئلته الثلاث بسرعة

④ حط الجوابين جنب بعض: «نفس كلود — بس هالمرة ما خمّن»

### شريحة 3.1 — المشاريع
إذا كل مرة تعيد تشرح منو انت — المشاريع تحل هالشي.

• تعليمات ثابتة + ملفات معرفة

• ملف هوية · ملف قرارات · مرجع ثابت

• ملفات قليلة ونظيفة، مو 50 ملف

• مشروع لكل سياق شغل

### شريحة 3.2 — 🎬 ديمو: مشروع المحتوى
⏱ 45 ث · جاهز: مشروع «المحتوى» فيه تعليمات + ملف هوية

① افتح المشروع ← وريهم التعليمات المخصصة

② افتح ملف الهوية ثواني

③ محادثة جديدة داخل المشروع: «سكربت ريل عن النوم» — بس هالسطر

④ «ما شرحت لهجتي ولا جمهوري — وطلع بصوتي»

### شريحة 4.1 — الآرتيفاكت
لحد هسه كلود يعطيك نص — تگدر تخليه يعطيك أداة.

• آرتيفاكت = صفحة / أداة / مستند جنب المحادثة

• بدل «احسب لي» ← «سوّي لي حاسبة»

• تعدّلها بالكلام

• حاسبة أسعار · تقويم محتوى · مولّد هوكات

• تشاركها برابط

### شريحة 4.2 — 🎬 ديمو: حاسبة سعر إعلان
⏱ 60 ث · سرّع انتظار الكتابة بالمونتاج

① «سوّي لي حاسبة سعر إعلان: المدخلات عدد المتابعين ونسبة التفاعل ونوع المنصة»

② جرّبها برقم حقيقي

③ تعديل واحد: «خلّ الألوان غامقة وضيف زر نسخ السعر»

④ «هاي مو جواب — هاي أداة أستخدمها كل يوم»

### شريحة 5.1 — السكلز
المشروع يتذكر منو انت. السكل يتذكر شلون تشتغل.

• مجلد + SKILL.md + سكربتات

• يقرا الوصف بس، ويفتح التفاصيل وقت الحاجة

• مشروع = معلومات · سكل = إجراء متكرر

• نسخت نفس البرومبت ثالث مرة؟ سوّه سكل

### شريحة 5.2 — 🎬 ديمو: سكل السكربت
⏱ 60 ث · جاهز: SKILL.md مفتوح، خط كبير

① وريهم الوصف بأول الملف: «هذا اللي كلود يقراه دايماً»

② انزل للهيكل: هوك ← ليد ← دورتين ← جسر ← طلب

③ شغّله: «سكربت ريل عن القهوة»

④ «نفس الهيكل، نفس اللهجة — كل مرة، بدون ما أعيد شي»

### شريحة 6.1 — الموصلات
لحد هسه انت تنقل المعلومات — الموصلات تخليه يجيبها بنفسه.

• درايف · جيميل · كالندر · نوشن (MCP)

• «شنو اجتماعاتي هالأسبوع وشنو أحضّر؟»

• البحث: تقرير بمصادره

• انت تتحكم بالصلاحيات — راجع قبل أي إرسال

### شريحة 7.1 — كلود كود
آخر طبقة: كلود ما يجاوب بس — يشتغل.

• كلود كود: يقرا، يكتب، يشغّل، يكمّل المهمة

• مو بس للمبرمجين

• البلگنز: I/O Studio من جملة وحدة

• من «تكتب برومبت» إلى «تدير فريق»

### شريحة 7.2 — 🎬 ديمو: كاروسيل من جملة
⏱ 40 ث · جاهز: تيرمنال غامق، خط 18+، رابط خبر منسوخ

① «سوّي كاروسيل عن هالخبر» + الرابط

② سرّع الانتظار بالمونتاج

③ افتح المجلد ← الصور طالعة بمقاسات المنصات

④ «جملة وحدة — والشغل خلص»

### شريحة 8.1 — الخاتمة
محادثة · مشروع · أداة · سكل · موصلات · وكيل.

• اختار طبقة وحدة فوق مستواك

• واجب: مشروع بملف هوية — أو حوّل برومبتك المتكرر لسكل

• أي طبقة انت واقف عندها هسه؟ گولي بالتعليقات
