# كلود للمستوى المتوسط — نص الملقّن
> كل عنوان = شريحة بنفس الترتيب (p-01 … p-18). أقسام «🎬 ديمو»: اضغط S للشاشة، أو وقّف التسجيل وسجّل الديمو بروحه.

## شريحة العنوان
إذا تستخدم كلود مثل گوگل — تسأل، تاخذ جواب، تسكر — فانت مستخدم جزء صغير منه.

• هالكورس مو للمبتدئين — أفترض تعرف تسأل وتعدّل الجواب

• اليوم: من البرومبت لين الإيجنت

• كل قسم بيه شي تطبقه اليوم

### شريحة 1.1 — السلّم
هذي خريطة الـ20 دقيقة — ست درجات.

• برومبت ← مشروع ← صفحة ← سكل ← موصلات ← إيجنت

• كل درجة تشيل شغل من عليك

• ما تحتاجها كلها — تحتاج الدرجة اللي فوقك

### شريحة 2.1 — النافذة
كلود ما يتذكر. كلود يقرا — المحادثة كلها، كل مرة.

• نافذة السياق = الطاولة اللي يشوفها

• المحادثة الطويلة تغطي تعليماتك الأولى

• موضوع جديد = محادثة جديدة

• قبل ما تسكر: «لخّص القرارات حتى أبدي محادثة جديدة»

• عدّل رسالتك بدل «لا مو هيچ»

### شريحة 3.1 — البرومبت المبني
البرومبت الزين مو الأطول — هو اللي ما يخلي كلود يخمّن.

• سياق ← مهمة ← قيود ← شكل ← مثال

• گول «ليش» ويّا كل قاعدة

• افصل البيانات بالوسوم <data>

• المثال يغلب الوصف

• «اسألني 3 أسئلة قبل ما تبدي»

• اطلب انتقاد مو مديح

### شريحة 3.2 — 🎬 ديمو: قبل / بعد

① «اكتب لي بوست عن الإنتاجية» ← الجواب العام

② محادثة ثانية: الصق البرومبت المبني

③ جاوب أسئلته بسرعة

④ «نفس كلود — بس هالمرة ما خمّن»

### شريحة 4.1 — برومبت ولا إيجنت؟
هذا أهم فرق بالكورس كله.

• البرومبت: انت تمسك الدفة — خطوة، جواب، انت تقرر الجاية

• الإيجنت: تعطيه هدف وأدوات — هو يقرر الخطوات

• الفرق مو بالذكاء — بمنو يقرر الخطوة الجاية

• مثال: «اكتب كابشن» = برومبت · «حلّل آخر 30 بوست وطلّع تقرير» = إيجنت

### شريحة 4.2 — حلقة الإيجنت
الإيجنت = نموذج + أدوات + حلقة.

• هدف ← يخطط ← ينفذ بأداة ← يشوف النتيجة ← يصحح ← يكرر

• يوقف لما يوصل لـ«خلصت» اللي انت حددته

• الأدوات: قراءة ملفات، بحث، تشغيل أوامر، موصلات

• بدون تعريف «خلصت» — يلف أو يوقف بنص الطريق

### شريحة 4.3 — متى أستخدم أيهم؟
مو كل شي يحتاج إيجنت.

• المهمة قصيرة وواضحة؟ برومبت

• الخطوات معروفة وتتكرر؟ سكل أو خطوات ثابتة

• الخطوات مو معروفة، يحتاج أدوات وتجربة؟ إيجنت

• الإيجنت أبطأ وأغلى — يستاهل لما يوفر عليك ساعة

• بريف الإيجنت: الهدف · شنو يعني خلصت · المسموح · الممنوع · وين يوقف ويسألك

### شريحة 5.1 — المشاريع
إذا كل مرة تعيد تشرح منو انت — المشاريع تحل هالشي.

• تعليمات ثابتة + ملفات معرفة

• ملف هوية · ملف قرارات · مرجع ثابت

• ملفات قليلة ونظيفة — كل شي ياكل من الطاولة

• مشروع لكل سياق شغل

### شريحة 6.1 — بناء صفحة
لحد هسه كلود يعطيك نص — تگدر تخليه يعطيك صفحة وأداة.

• الآرتيفاكت: صفحة أو أداة تطلع جنب المحادثة

• بدل «احسب لي» ← «سوّي لي حاسبة»

• وصف الصفحة: لمنو · شنو الهدف · الأقسام · الشكل

• تعدّلها بالكلام، وتشاركها برابط

### شريحة 7.1 — السكلز
المشروع يتذكر منو انت. السكل يتذكر شلون تشتغل.

• سكل = مجلد فيه SKILL.md ومرات سكربتات وقوالب

• كلود يقرا الوصف بس، ويفتح التفاصيل وقت الحاجة

• مشروع = معلومات · سكل = طريقة شغل

• نسخت نفس البرومبت ثالث مرة؟ سوّه سكل

### شريحة 8.1 — الموصلات وMCP

• درايف · جيميل · كالندر · نوشن

• انت تتحكم بالصلاحيات — راجع قبل أي إرسال
