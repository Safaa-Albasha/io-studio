# كلود بعد مرحلة المبتدئ — نص الملقّن

## 1
إذا تستخدم كلود مثل گوگل — تسأل، تاخذ جواب، تسكر — فانت مستخدم عشرة بالمية منه.
- هالكورس مو للمبتدئين
- خمس طبقات: مشروع ← أداة ← سكل ← موصلات ← وكيل
- كل قسم بيه شي تطبقه اليوم

## 2
كلود ما يتذكر. كلود يقرا — المحادثة كلها، كل مرة.
- نافذة السياق = الطاولة اللي يشوفها
- المحادثة الطويلة تغطي تعليماتك الأولى
- موضوع جديد = محادثة جديدة
- ملخص التسليم: «لخّص القرارات حتى أبدي محادثة جديدة»
- عدّل رسالتك بدل «لا مو هيچ»
- ديمو: ملخص ← محادثة جديدة

## 3
البرومبت الزين مو الأطول — هو اللي ما يخلي كلود يخمّن.
- سياق ← مهمة ← قيود ← شكل ← مثال
- گول «ليش» مع كل قاعدة
- افصل البيانات بالوسوم <article>
- المثال يغلب الوصف — الصق بوستاتك
- «اسألني 5 أسئلة قبل ما تكتب»
- التفكير المطوّل للمسائل الصعبة
- اطلب انتقاد مو مديح
- ديمو: قبل / بعد

## 4
إذا كل مرة تعيد تشرح منو انت — المشاريع تحل هالشي.
- تعليمات ثابتة + ملفات معرفة
- ملف هوية · ملف قرارات · مرجع ثابت
- ملفات قليلة ونظيفة، مو 50 ملف
- مشروع لكل سياق شغل
- ديمو: سكربت بسطر واحد بلهجتي

## 5
لحد هسه كلود يعطيك نص — تگدر تخليه يعطيك أداة.
- آرتيفاكت = صفحة / أداة / مستند جنب المحادثة
- بدل «احسب لي» ← «سوّي لي حاسبة»
- تعدّلها بالكلام
- حاسبة أسعار · تقويم محتوى · مولّد هوكات
- تشاركها برابط
- ديمو: حاسبة سعر إعلان

## 6
المشروع يتذكر منو انت. السكل يتذكر شلون تشتغل.
- مجلد + SKILL.md + سكربتات
- يقرا الوصف بس، ويفتح التفاصيل وقت الحاجة
- مشروع = معلومات · سكل = إجراء متكرر
- مثال: سكل السكربت (هوك ← ليد ← دورتين ← جسر ← طلب)
- نسخت نفس البرومبت ثالث مرة؟ سوّه سكل
- ديمو: افتح SKILL.md وشغّله

## 7
لحد هسه انت تنقل المعلومات — الموصلات تخليه يجيبها بنفسه.
- درايف · جيميل · كالندر · نوشن (MCP)
- «شنو اجتماعاتي وشنو أحضّر؟»
- البحث: تقرير بمصادره
- انت تتحكم بالصلاحيات — راجع قبل أي إرسال

## 8
آخر طبقة: كلود ما يجاوب بس — يشتغل.
- كلود كود: يقرا، يكتب، يشغّل، يكمّل المهمة
- مو بس للمبرمجين
- البلگنز: I/O Studio من جملة وحدة
- من «تكتب برومبت» إلى «تدير فريق»
- ديمو: كاروسيل عن خبر

## 9
محادثة · مشروع · أداة · سكل · موصلات · وكيل.
- اختار طبقة وحدة فوق مستواك
- واجب: مشروع بملف هوية — أو حوّل برومبتك المتكرر لسكل
- أي طبقة انت واقف عندها هسه؟ گولي بالتعليقات
