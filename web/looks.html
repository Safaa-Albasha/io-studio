مكتبة الألوان والفلاتر

… لوك — اسحب على الصورة تشوف قبل/بعد. كل لون له ملف .cube يشتغل بـCapCut وPremiere وDaVinci.

شلون أطبّق اللوك؟ 
node engine/grade.js apply video.mp4 --look teal_orange --strength 0.7
node engine/grade.js preview video.mp4 --looks teal_orange,warm_film,ramadan_night --out sheet.jpg
node engine/grade.js lut teal_orange --out teal_orange.cube
node engine/grade.js auto video.mp4 --look natural_plus

بـCapCut: تعديل ← Adjust ← LUT ← استيراد ملف .cube. المؤثرات (حبيبات، تظليل، توهج…) ما تنحط بـLUT — طبّقها بالأمر.

ما لگيت شي — جرّب كلمة ثانية.
