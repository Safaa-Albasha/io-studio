ابدأ مع آي أو استوديو

I/O Studio · «فكرتك تدخل… والذكاء يكمّل الإبداع» · الإصدار 4.2.1

آي أو استوديو إضافة (بلقن) مجانية لـ Claude Code، معمولة لصنّاع المحتوى العرب. تحچي ويّا Claude بلهجتك، وهو يسوّي لك كاروسيل، سكربت، مونتاج ريل بكابشن عربي، موشن، كفرات، بودكاست، وإحصائيات، لـ إنستقرام ويوتيوب وتيك توك بالتساوي.

١شنو تحتاج قبل

Claude Codeبالترمنال أو تطبيق سطح المكتب، ويّا اشتراك Claude
Node.js 18 أو أحدثمن nodejs.org
Python 3لأدوات الفيديو والصور
ffmpegللمونتاج. ما عندك؟ أداة الفحص تنصّبه لك

٢التنصيب: ٣ خطوات

1
افتح Claude Code واكتب هالأمر (يضيف المتجر):/plugin marketplace add Safaa-Albasha/io-studio
2
نصّب البلقن:/plugin install io@io-studio
3
سكّر Claude Code وافتحه من جديد، وبعدها گول «ابدأ» أو اكتب:/io:io-start

٣أول مرة

  • Claude يسألك أسئلة بسيطة يعرّف بيها نفسك: اسمك، مجالك، لهجتك، ألوانك، وحساباتك. يحفظها بمجلد .io/ داخل مشروعك، فكل شي يطلع بهويتك.
  • سوّ مجلد لكل مشروع (مثلاً «محتواي») وافتح Claude Code منه.
  • تريد يفحص جهازك وينصّب الناقص (ffmpeg، وِسبر للكابشن، قصّ الشخص…)؟ گول «افحص جهازي» أو اكتب /io:io-doctor

٤البرنامج بالمتصفح

گول «افتح البرنامج»: تنفتح صفحة فيها الأفكار، الجدول، المونتاج بتايملاين، ومكتبة ٣٥٨ حركة ولوكات وأصوات ودروس. كل شي يشتغل على جهازك، وبياناتك ما تطلع منه.

٦التحديث

لما ينزل إصدار جديد، اكتب الأمرين بالترتيب، وبعدها سكّر Claude Code وافتحه: /plugin marketplace update io-studio /plugin update io@io-studio

💡 نصايح

  • Claude يعرض لك النتيجة ويسألك قبل أي شي نهائي، مثل النشر.
  • ما عجبتك؟ گول شنو تغيّر: «كبّر الخط»، «أسرع»، «لون ثاني».
  • الدليل المصوّر الكامل (٢٥ صفحة) داخل البرنامج: زر «📖 دليل الاستخدام».

🛠️ إذا صار شي

  • أداة ما تشتغل؟ /io:io-doctor يفحص وينصّب الناقص.
  • الأوامر ما تطلع بعد التنصيب؟ سكّر Claude Code وافتحه.
  • نسخة قديمة؟ سوّ خطوة التحديث (٦).
