# I/O Studio · آي أو استوديو

<img src="web/lib/logo.svg" width="64" alt="I/O Studio">

**`I` ── «فكرتك تدخل… والذكاء يكمّل الإبداع» ── `O`**

I = فكرتك (Input) · O = فيديوك (Output) · والذكاء الاصطناعي بالنص.

أدوات عربية **مجانية** لصنّاع المحتوى، تشتغل داخل Claude Code كإضافة (Plugin)، ويّا صفحتين بالمتصفح بدون سيرفر: **استوديو تسجيل** و**لوحة إحصائيات**.
كل أداة تطلع شغلها لـ **إنستقرام ويوتيوب وتيك توك بالتساوي**.

من صفاء البشا — [@safaaio](https://instagram.com/safaaio)

## شنو بيها

- **البرنامج الكامل `app.html`:** الأفكار (ومنها أفكار يومية من ترند الحسابات اللي تتابعها) ← الجدول (المنصات الثلاث بالتساوي) ← البناء ← المونتاج (تايملاين وفلاتر وصوت) ← مكتبة كل اللي متركّب: ٢٤٢ حركة، قوالب، أصوات، لوكات، ٥٦ درس — وكلها حسب نوع حسابك (طبيب، مهندس ديكور، رائد أعمال، صانع محتوى، مدرّس/طالب، شخص عادي؛ فيديو لو بودكاست). شغّله: `node engine/serve.js --open app.html`.

## التنصيب

```bash
/plugin marketplace add Safaa-Albasha/io-studio
/plugin install io@io-studio
```
بعدها گول: **«ابدأ»** — أو `/io:io-start`.

**التحديث:** `/plugin marketplace update io-studio` ثم `/plugin update io@io-studio` ثم سكّر Claude Code وافتحه من جديد.

**📖 الدليل خطوة بخطوة بالصور:** [`docs/tutorial/io-studio-tutorial.pdf`](docs/tutorial/io-studio-tutorial.pdf) — الطريقتين («عندي فيديوهات» و«ما عندي فيديو، خلّي الذكاء يسوي»)، كل تبويبات البرنامج، الإحصائيات، بنك الحركات، وورقة «ابدأ هنا» بشنو تگول لـ Claude. وبالبرنامج نفسه: زر «📖 دليل الاستخدام». ودليل التنصيب: [`docs/guide/io-studio-guide.pdf`](docs/guide/io-studio-guide.pdf).

**يحتاج:** Node.js 18+ وPython 3. للفيديو: `ffmpeg` (محرّك المونتاج يجهّز الباقي بنفسه بأول مرة).  للتصدير PNG/MP4 من HTML: Playwright (`npm i -g playwright && npx playwright install chromium`). للكابشن التلقائي: `pip install openai-whisper` (اختياري).

## الصفحتين بالمتصفح

```bash
node engine/serve.js        # من مجلد الإضافة — أو Claude يشغّلها لك
```
- `http://localhost:4747/studio.html` — **استوديو التسجيل**: افتح مجلد درس (صور شرائح + `prompt.md` + `scene.json` اختياري)، شغّل الكاميرا، واختار عمودي 9:16 أو عرضي 16:9. **R** يسجّل، **Space** الشريحة التالية. الفيديو ينحفظ بـ `recordings/` داخل مجلد الدرس (Chrome/Edge). يستورد عرض HTML ويحوّله صور.
- `http://localhost:4747/course-studio/studio.html` — **استوديو الكورسات**: استوديو أكبر — PDF، شاشتين، ميني بار، MP4 عادي جاهز للمونتاج، وحرق نص الملقّن.
- `http://localhost:4747/dashboard.html` — **الإحصائيات**: استورد ملفات التصدير لكل منصة (أو `stats.json`)، وشوف الثلاث جنب بعض. البيانات تبقى بجهازك.

الكاميرا والحفظ بالمجلد يحتاجون `localhost` أو `https` — لهذا السيرفر الصغير (بدون أي مكتبات).

## ملفات الهوية (بمجلد مشروعك)

```
.io/
  creator-profile.md   مَن أنت، جمهورك، صوتك، قيودك
  theme.json           الألوان، الخط، الحساب، نوع الأرقام
  project.json         المنصات الثلاث وحساب كل منصة
  stats.json           الإحصائيات (من dashboard)
lessons/<درس>/         slides/ · prompt.md · scene.json · recordings/
output/                carousels/ · covers/ · motion/ · video/ · publish/
```

## أوامر المحرّك (Claude يشغّلها، وتگدر تشغلها بنفسك)

| الأمر | شنو يسوي |
|---|---|
| `node engine/config.js init\|check\|lesson <اسم>` | ملفات الهوية، فحصها، مجلد درس جديد |
| `node engine/shoot.js file.html --selector .slide` | HTML ← PNG (كاروسيل، كفرات، عروض) |
| `node engine/render.js scene scene.json` | درس متحرك ← MP4 |
| `node engine/render.js motion file.html` | موشن ← MP4 (`__seek(t)`) |
| `node engine/video.js fix\|plan\|cut\|captions\|burn\|variants` | قص وكابشن ونسخ المنصات |
| `node engine/stats.js import\|fetch\|summary` | الإحصائيات |
| `node engine/arabic-qa.js <مجلد\|ملف>` | فحص النص العربي قبل التسليم (حروف ما يرسمها الخط، وصل مكسور، اتجاه مخلوط، تشكيل متراكم) |
| `node engine/redact.js stills\|apply <فيديو> --rects rects.json` | تمويه البيانات الخاصة بتسجيل الشاشة + فحص إنها انمسحت |
| `node engine/podcast-batch.js propose\|select\|status` | حلقة طويلة ← دفعة ريلات تكمل بعد أي توقف |
| `node engine/publish-pack.js check\|render <copy.json>` | فحص وصف النشر للمنصات الثلاث ← `output/publish/*.md` |
| `node engine/stickers.js list\|render <id>` | ملصقات وإيموجي متحركة (Lottie/SVG) ← PNG شفاف للمشاهد |

## التطوير

```bash
node --test                       # الاختبارات (من جذر المستودع)
claude --plugin-dir .             # جرّب تعديلاتك
claude plugin validate .          # فحص البلقن والمتجر
```

**شكل المستودع:** البلقن بجذر المستودع `Safaa-Albasha/io-studio` — بيه `.claude-plugin/plugin.json` (البلقن `io`) و`.claude-plugin/marketplace.json` (المتجر `io-studio`، المصدر `./`). كل شي يحتاجه البلقن داخل هالمجلد.
