# دليل التصوير: كورس «كلود بعد مرحلة المبتدئ»

## 1 · قبل يوم التصوير (مرة وحدة)
- **المتصفح:** Chrome أو Edge. سفاري وفايرفوكس ما يشتغلون ويّا الاستوديو.
- **ماك:** إعدادات النظام ← الخصوصية والأمن ← تسجيل الشاشة وصوت النظام ← فعّل Chrome، وبعدين سكّره وافتحه.
- **حضّر الديموهات بحساب كلود نظيف:**
  - مشروع «المحتوى» بتعليمات وملف هوية.
  - البرومبت المبني منسوخ بملف.
  - طلب صفحة الهبوط منسوخ.
  - 3 كابشنات من شغلك.
  - السكلز مفعّلة من الإعدادات.
  - مجلد فاضي لديمو كلود كود.
- **سوّي كل ديمو مرة تجربة.** هيچ تعرف وين يطوّل كلود ووين ممكن يطلع شي غريب.

## 2 · المكان والعدّة
| | الإعداد |
|---|---|
| الكاميرا | بمستوى عيونك، والملقّن جنبها أو تحتها مباشرة حتى نظرك يبقى قريب من العدسة |
| الإضاءة | ضو قدامك (شباك أو سوفت بوكس) بزاوية 45°، لا ضو وراك |
| الصوت | مايك لاقط قريب أو دبوس. الصوت أهم من الصورة |
| الخلفية | هادئة. إذا تقدر، لمسة ضو أزرق (لون هويتك #2EC4F0) |
| الشاشة | إذا عندك شاشتين: الاستوديو على وحدة، والشغل على الثانية |
| التنبيهات | سكّرها كلها (ماك: Do Not Disturb · ويندوز: Focus) |

## 3 · شغّل الاستوديو
```bash
node engine/serve.js
```
افتح `http://localhost:4747/course-studio/studio.html` بـ Chrome، وبعدين:
1. «📁 اختر مجلدًا» ← `lessons/claude-advanced` (اسمح بالتعديل حتى ينحفظ الفيديو بيه).
2. بخانة «نص الملقّن» تأكد إنه مختار `prompt.md`.
3. شغّل الكاميرا والمايك، واختار المايك الصحيح من القائمة.
4. اضغط **F** لملء الشاشة.

**اختصارات استوديو الكورسات** (الكيبورد لازم يكون إنگليزي):
| المفتاح | شنو يسوي |
|---|---|
| **R** | يبدي التسجيل (عدّ 3-2-1)، ويوقفه |
| **←** | الشريحة الجاية |
| **→** | الشريحة السابقة |
| **مسافة** | الملقّن: تشغيل / إيقاف |
| **Shift + ↑/↓** | الملقّن أسرع / أبطأ |
| **S** | الشاشة بدل الشريحة / ورجوع |
| **L** | مؤشر ليزر |
| **D** | رسم بالفأرة |
| **F** | ملء الشاشة |

> إذا المفاتيح ما تستجيب: اضغط على الشريحة مرة، لأن المؤشر يكون علگان بقائمة.

## 4 · التسجيلات الخمسة
| # | شنو | شلون |
|---|---|---|
| **A** | الشرح كامل، تقريباً 14 دقيقة | كاميرا + شرائح + ملقّن. توصل لشريحة ديمو؟ گول جملة الدخول، وكمّل بـ**←** للشريحة الجاية. الديمو ينحط مكانها بالمونتاج |
| **D1** | قبل / بعد | تسجيل شاشة، والكاميرا صغيرة بالزاوية |
| **D2** | صفحة هبوط | نفس الشي |
| **D3** | سكل من الصفر | نفس الشي |
| **D4** | كلود كود يبني الصفحة | نفس الشي، والتيرمنال بخط 18+ |

**شلون تسجّل ديمو بالاستوديو:**
1. **S** ← Chrome يسألك شنو تشارك.
   - عندك شاشتين: اختار الشاشة الثانية.
   - عندك شاشة وحدة: اختار **التبويب** أو **النافذة** مال كلود، لا الشاشة الكاملة.
2. **R**، سوّي الديمو، وبعدين **R** توقف.
3. تريد تأشّر على شي؟ **L** للّيزر أو **D** للرسم.

**ليش منفصلة؟** إذا غلطت بالديمو تعيده بروحه، وانتظار كتابة كلود تسرّعه بالمونتاج.

## 5 · وقت الكلام
- سجّل **قسم قسم** بالتسجيل A. إذا غلطت: اسكت ثانيتين، وأعد الجملة من أولها. السكتة تسهّل القص.
- الملقّن نقاط مو نص. اقرا الجملة الأولى مثل ما هي، والباقي بكلامك.
- خلّ عينك بالعدسة بالجملة الأولى والأخيرة من كل قسم.
- قبل الشرائح الثقيلة (البرومبت المبني، برومبت ولا إيجنت، حلقة الإيجنت) خذ نفس وبطّئ. هذي قلب الكورس.
- كل 3-4 أقسام اشرب مي وشيك على الصوت.

## 6 · بعد التسجيل
- الفيديوهات تنحفظ بـ`lessons/claude-advanced/` بصيغة MP4.
- io-video-cut: شيل السكتات والإعادات من A.
- ركّب D1 لين D4 مكان شرائح الديمو (p-05، p-11، p-13، p-17).
- سرّع انتظار كلود بالديموهات 2× لين 4×، وكبّر (زوم) على الأجزاء المهمة.
- طلّع 3-4 ريلات: «برومبت ولا إيجنت»، «النافذة»، وديمو «قبل / بعد».
