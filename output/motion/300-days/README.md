## الملفات
- `project.json` + `scenes/*.js`: الفيلم بمحرّك الموشن (`skills/io-video-editor/motion`).
- `sound.py`: الصوت. خلفية درون مولّدة بالكود ومؤثرات من `library/sfx`، والناتج `audio/mix.wav`.
- `fonts/`: خط Alexandria (رخصة OFL) من Google Fonts.
- `final.mp4`: النسخة النهائية.

## إعادة البناء
```bash
cd skills/io-video-editor/motion
node render.js ../../../output/motion/300-days preview 2 30 45   # معاينة
node render.js ../../../output/motion/300-days all --fresh          # الفيلم
cd ../../../output/motion/300-days && python3 sound.py
ffmpeg -i audio/mix.wav -af loudnorm=I=-14:TP=-1.5:LRA=11 -ar 48000 -ac 2 audio/mix_norm.wav
ffmpeg -i renders/video.mp4 -i audio/mix_norm.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -shortest -movflags +faststart final.mp4
```

## ملاحظة عن «صُنع بـ Fable 5.2»
السطر موجود بالمشهد 5 (شريحة الموديل) والمشهد 9. إذا الفيلم ما انبنى بجلسة Fable 5.2، غيّر النص بالملفين `scenes/s5_type.js` و`scenes/s9_end.js` حتى الكلام يبقى صحيح.
