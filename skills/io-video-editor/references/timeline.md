# 🎞️ صفحة التايملاين — تشوف الفيديو مقسوم لأجزائه وتعدّله بيدك

```bash
python3 studio/studio.py <work> [port]      # نفس خادم الاستوديو (بايثون بس، بلا مكتبات) — ويندوز · ماك · لينكس
# افتح: http://127.0.0.1:8792/timeline
```
⚠️ مثل الاستوديو: يفتح على الشبكة المحلية بلا كلمة سر — لا تشغّله على شبكة عامة.

## 1) وش كان موجود ووش كان ناقص
| موجود قبل (`/m` — studio-mobile.html) | كان ناقص |
|---|---|
| تايملاين بزمن **الإخراج** (بعد القص): فيديو · مشاهد · كابشن · نصوص · بي-رول · صوت · ورا الراس | ما تشوف **الأجزاء المحذوفة** (السكتات) — فما تقدر ترجّع كلمة انقصّت |
| تعديل القص بأزرار ±0.5 ث وحذف مقطع | سحب الأطراف · التصاق بحدود الكلمات · قسمة عند المؤشر · ترتيب بالسحب |
| ستايل الكابشن · مؤثر على كلمة · مشاهد · بي-رول · تصدير | موجة الصوت · صور مصغّرة · تعديل نص الجملة مع شرط عدد كلمات وِسبر |
| رسم كامل | «طبّق» يعيد **بس** الخطوات اللازمة · معاينة مقطع قصير مرسوم · تراجع/إعادة للقص |

فالقرار: **صفحة ثانية بنفس الخادم** (`studio/timeline.html` + `studio/timeline-core.js`) — نفس الملفات ونفس السكربتات، ولا تلمس `/m`.
ليش مو صفحة مستقلة بـFile System Access؟ لأن «طبّق» لازم يشغّل ffmpeg وكروم والسكربتات، وهالـAPI ما يشتغل بفايرفوكس/سفاري ولا بالجوال.

## 2) التصميم
**محور الزمن = ثواني المصدر `src.mov`** — لأنها الشي الوحيد اللي ما يتغيّر مهما قصّيت؛ فتشوف السكتات المحذوفة (مخطّطة) وتقدر ترجّعها.
**الزمن يمشي من اليسار لليمين** مثل كل برامج المونتاج (بريمير · كاب كت · دافنشي)، والعناوين والأزرار عربية من اليمين. قرار مقصود: الموجة والكلمات والأرقام كلها تقرأ يسار←يمين.

```
┌──────────────────────────────────────────────────────────────┬─────────────┐
│                       [ المشغّل 9:16 ]                       │ اللوحة:     │
│                  حيّة · النهائي · معاينة مقطع                │ المحدد      │
│                                                              │ + «طبّق»    │
├──────────────────────────────────────────────────────────────┴─────────────┤
│ المونتاج  [ 1 ][     2     ][ 3 ][        4        ]   ← بترتيب الإخراج (اسحب لترتّب)
│ ▶ J K L  00:08.44 / 00:44.03 │ ✂ قسّم │ ⌫ │ 🧲 │ [مؤثر▾] ＋ │ − + ⤢ │ 👁 │ طبّق │
├────────┬──────────────────────────────────────────────────────────────────┤
│ الزمن   │ 00:00     00:05     00:10     00:15 ...                     (يسار→يمين)
│ المقاطع │ ////[▌1 🖼🖼🖼▐]/[▌2 🖼🖼🖼🖼🖼🖼🖼▐]/////[▌3 🖼🖼▐]/[▌4 🖼🖼🖼🖼▐]   //// = محذوف
│ الصوت   │ ▁▃▇▅▃▁▇▆▃  ▃▅▇▆▅▃▂▅▇▆▃▁       ▂▅▇▆▃  ▃▆▇▅▃▂▅▇▆▃       (رمادي = محذوف)
│ الجمل   │ [هلا بيكم اليوم…][أول شي الهوك…]       [هلا بيكم…][أول شي…]
│ الزوم   │ [×1.00]         [×1.08]                [×1.00]   [×1.06]
│ المؤثرات│ ◆ووش         ◆ووش  ◆نقرة ◆نقرة  ◆فقاعة
│ المشاهد │ [ملء الشاشة ......................................]
└────────┴──────────────────────────────────────────────────────────────────┘
```
**الجوال** (≤ 760px): عمودي — المشغّل فوق، تحته شريط المونتاج والأدوات (تتمرّر بالعرض)، ثم المسارات (تتمرّر بالعرض)، ثم اللوحة.
فاتح/داكن تلقائي مع زر ◐.

### المسارات ومصدرها
| المسار | من وين | ملاحظات |
|---|---|---|
| المقاطع | `cut.json ← keep` + صور مصغّرة (ffmpeg) | لون لكل مقطع ورقم ترتيبه بالإخراج · الفراغ المخطّط = سكتة/محذوف · المقطع المحذوف يبقى مخطّط أحمر وترجّعه |
| الصوت | قمم الموجة من ffmpeg (بالخادم، مرة وحدة) | علامات برتقالية صغيرة = حدود كلمات وِسبر (لما تكبّر) |
| الجمل | `a.json` (توقيت وِسبر) + نص `fixes.json` | جملة باهتة = كلها داخل جزء محذوف |
| الزوم | `cut.json ← zooms` (مفتاحه بداية المقطع) | المقطع المقسوم يورث زوم أبوه (نفس منطق 03) |
| المؤثرات | `sfx.json` (زمن إخراج → يتحوّل لزمن المصدر) | معيّن أحمر = داخل جزء محذوف |
| المشاهد | `studio.json ← scenes/stickers` أو `SCENES` بـcompose.html | للعرض بس — تعديلها من `/m` |

### كل حركة وش تكتب
| الحركة | كيف | تكتب (عند «طبّق») |
|---|---|---|
| قصّ | اسحب طرف المقطع (يلتصق بحدود الكلمات؛ Alt أو 🧲 يوقفه) أو اكتب الرقم باللوحة | `cut.json ← keep` |
| قسّم | `S` عند المؤشر | `keep` (مقطعين) + `zooms` للاثنين |
| احذف/رجّع | `Del` على المقطع المحدد | `keep` + `_tl_removed` (عشان يبقى يبان ويترجّع) |
| رتّب | اسحب المربع بشريط «المونتاج» | ترتيب `keep` (03 يركّبه بالترتيب المكتوب) |
| الزوم | منزلق باللوحة (1.00–1.30) | `cut.json ← zooms` + `_zsrc` |
| نص جملة | ضغطتين على الجملة (Enter يحفظ، Esc يلغي) أو باللوحة | `fixes.json ← fix[i]` |
| مؤثر | اختر النوع ثم `X`/＋ عند المؤشر، أو ضغطتين بمسار المؤثرات · اسحبه لتحريكه · `Del` يحذفه | `sfx.json` (يتحوّل لزمن الإخراج الجديد) |

**شرط الكابشن** (نفس `02_captions.py`): عدد كلمات الجملة = عدد كلمات وِسبر. الصفحة تعدّ وتمنع الحفظ وتطلّع الخطأ بالأحمر.
كلمتين بكلمة وحدة؟ اربطها بـ`_` (`ريل_يوقف` ← «ريل يوقف»). تبي تشيل كلمة من الكابشن والصوت يبقى؟ اكتب `~` مكانها (= `""` بـfixes.json).
الجملة المكتوبة نص (وِسبر هلوس) ما عليها شرط.

**أصوات المكتبة:** لو موجود `library/sfx/catalog.json` (بجذر البلقن أو داخل السكل) تطلع بالقائمة تحت «المكتبة» وتنكتب `sfx.json ← "lib": [[ثانية, "id"], …]`.
⚠️ `05_sfx.py` الحالي ما يقرأ `lib` — تنحفظ وتبان بالتايملاين، لكن ما تنسمع بالملف النهائي لين يدعمها 05_sfx.

### المشغّل — ثلاث حالات
- **حيّة** (الافتراضي): يشغّل المصدر ويقفز فوق كل جزء محذوف بترتيب المونتاج الحالي — تشوف تعديلك فوراً **بلا رسم**، مع كابشن تقريبي فوقه. يستخدم نسخة خفيفة `.timeline/proxy.mp4` (H.264 بمفاتيح كل نص ثانية → قفز دقيق بأي متصفح حتى لو المصدر HEVC/HDR)، ولين تجهز يشغّل `src.mov`.
- **النهائي**: `ad-final.mp4` (أو `ad-master.mp4`) — المؤشر يتحوّل لزمن المصدر حسب القص المطبّق.
- **معاينة مقطع**: آخر `.timeline/preview.mp4`.

### «طبّق» — يعيد بس اللازم (شغل بالخلفية مع نسبة وسجل)
| تغيّر | الخطوات |
|---|---|
| المؤثرات بس | `05_sfx.py` → `06_encode.sh` (ثواني) |
| نص الكابشن | `02_captions.py` → `04_render_frames.js all --force` → 05 → 06 |
| الزوم | `03_cut_zoom.py` → فريمات `vfr/` → 04 → 05 → 06 |
| القص (قص/قسمة/حذف/ترتيب) | 02 → 03 → فريمات → تحريك المشاهد والملصقات (studio.json) → 04 → 05 → 06 |

- قبل أي شي ينسخ cut/caps/fixes/sfx/studio لـ`.studio_bak/` — زر «تراجع عن آخر قص» بالاستوديو `/m` يرجّعها.
- كلمات وِسبر اللي صارت بجزء محذوف تنخفى من الكابشن وقت 02 بس (fixes.json يرجع زي ما هو) — بدونها 02 يلصقها بطرف المقطع الجار.
- القص يلغي «ورا الراس» (behind.json) لأن الفريمات تغيّرت — زي `/m`.
- يطلع `ad-final.mp4` جديد ويمسح `ad-master.mp4` القديم (صار قديم). المعايرة (06b) تسويها بعدين من `/m` أو يدوي.
- **معاينة مقطع** (👁): يرسم المقطع المحدد (أو ±3 ث حول المؤشر، أقصى 20 ث) بـ`04_render_frames.js <work> range a b` ويجمّعه مع الصوت والمؤثرات. يشتغل على آخر نسخة مطبّقة — لو عندك قص/كابشن غير مطبّق ينبّهك تطبّق أول.

### تراجع ومسودة
- `Ctrl+Z` / `Ctrl+Shift+Z` (أو `Ctrl+Y`) — 150 خطوة، لكل التعديلات قبل «طبّق».
- كل تعديل ينحفظ مسودة بـ`.timeline/draft.json` — تسكّر الصفحة وترجع تلقاها (لو ما تغيّر القص من برّا). «ألغِ التعديلات» يرجّع للملفات.

### الاختصارات
`مسافة` تشغيل/إيقاف · `J` رجوع 2 ث · `K` إيقاف · `L` تشغيل (مرة ثانية تسرّع ×1.5 ×2) · `←` `→` فريم (`Shift` ثانية) · `S` قسّم · `Del` حذف/رجوع · `X` مؤثر · `Ctrl`+عجلة تكبير حول الماوس · `+` `-` `0` تكبير/تصغير/الكل · `Esc` إلغاء التحديد.

## 2.5) تعديل جملة بمكانها + طلبات لـ Claude
- **ضغطة وحدة على جملة** بمسار «الجمل» = نافذة صغيرة فوقها بنصّها: «احفظ الجملة» يغيّر `fix[i]` لهالجملة بس (نفس شرط عدد كلمات وِسبر)، و«احفظ وطبّق» يطبّق على طول — الخطة (`TL.plan`) تعيد بس الكابشن ← الرسم ← المؤثرات ← التجميع (القص والفريمات ما تنعاد).
- **«خلّي Claude يعيد صياغتها»** بنفس النافذة، و**«🤖 عدّل لي…»** باللوحة (الصوت · الكابشن · أي شي — على المقطع/الجملة المحددة أو الفيديو كله): يدوّر على سيرفر آي أو استوديو (`engine/serve.js` على 127.0.0.1:4747–4800، يفضّل اللي مجلد مشروعه فيه مجلد الشغل) ويرسل `POST /api/queue` = `{type:'edit', target:'caption'|'audio'|'general', work, segment:{index,start,end,text}|{start,end}, note}` (CORS مسموح لصفحات localhost). سكل **io-autopilot** يستلمه.
- السيرفر مو شغّال (أو فاتح التايملاين من الجوال على الشبكة)؟ تطلع نفس الطلب كأمر جاهز يلصقه بالشات (`TL.chatCommand`).
- `GET /api/tl/state` صار فيه `work` (مسار مجلد الشغل) حتى الطلب يعرف وين.

## 2.6) 🎯 التتبّع
زر «🎯 تتبّع» (أو <kbd>T</kbd>) يحوّل المشغّل لـ`cutz.mp4` ويفتح لوحة التتبّع: ارسم سطح/صندوق/نقطة على فريم واقف → «تتبّع من هنا» → الشكل يمشي فوق الفيديو · «صلّح من هنا» · «اربط» بعنصر `studio.json` (`track: "<الاسم>"`). التفاصيل والملف: `references/tracking.md`.
