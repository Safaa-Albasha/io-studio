## 9) ستايل «لقطة» (سؤال يومي)

شكل سلسلة أسئلة يومية («ليش ما يحس بالحار؟»): رسمة كاملة للشخص، علامة صغيرة بأقواس زوايا فوق، أيقونة «؟» جنب الراس،
ولوح غامق تحت (تقريباً 40٪ من الطول) فيه العلامة صغيرة وشرطة بلون الهوية وسؤال عريض سطرين ينتهي بـ«…» أو «؟».
تصميم أصلي بكودنا — ما أخذنا أي صورة أو ملف منهم، والعلامة نصها من عندك (`brand`).

| الحركة | شنو تسوي |
|---|---|
| 228 `questionCard` | اللوح الغامق + العلامة + الشرطة + السؤال كلمة كلمة (كلمات كاملة، داخل المنطقة الآمنة 9:16) |
| 229 `iconPop` | فقاعة ؟ · ! · zZz · لمبة تفرقع جنب الراس وتتمايل (تلحق الوجه لو فيه `face`) |
| 230 `kenBurns25D` | زوم وتحريك بطيء على صورة ثابتة بطبقتين (الشخص بالقصّ، أو النص التحتاني كبديل) مع نَفَس خفيف |
| 231 `brandBracket` | علامتك بين أقواس زوايا ترتسم |
| 232 `seriesEndCard` | «الحلقة الجاية: …» بنفس الشكل + كبسولة «تابع عشان ما تفوتك» |

مثال مشهد كامل:
```js
ill(X);                                   // الصورة
FX.kenBurns25D(MV, t, { s: 0, dur: 6, draw: ill, person: MV.person });
FX.brandBracket(MV, t, { s: 0, text: 'اسمك', x: 140, y: 150, size: 34 });
FX.iconPop(MV, t, { s: 1.0, icon: '?', face: MV.faceAt });
FX.questionCard(MV, t, { s: 0.2, text: 'المسار اليسار…\nمنو الصح؟', brand: 'اسمك' });
```
