# انسخ ستايل أي فيديو — «بصمة ستايل»

مأخوذ ومعدّل من Reel Studio (MIT، © 2026 Mohamed Abdou — `instructions/STYLE-LEARNING.md`). الأداة: `${CLAUDE_SKILL_DIR}/scripts/style_analyze.py`.

**القاعدة:** نتعلّم **قرارات** المرجع (إيقاع، حركة، تسلسل الكابشن، مادة الشكل) — مو لقطاته ولا صوته ولا نصه ولا هويته. المرجع يبقى كما هو، وما يدخل فيديو المستخدم منه ولا فريم. ألوان وهوية المستخدم من `.io/` تبقى.

## ١. سجّل المرجع (بلا ما تفحص ملفات ثانية)
- ملف عنده ← اسمه بالضبط. رابط ← `yt-dlp -f "bv*[height<=1080]+ba/b" -o ref.mp4 "<الرابط>"` (للتحليل بس، ولا ينستخدم بالمونتاج).
- مجلد المشروع = مجلد الفيديو الجديد (`<work>`) أو مجلد يسمّيه.

## ٢. قِس
```bash
python3 "${CLAUDE_SKILL_DIR}/scripts/style_analyze.py" analyze <ref.mp4> --out <work> --id ref-a
```
يكتب `<work>/style-analysis/ref-a/` (probe · cuts · motion · look · text · audio · `sheet.jpg` · `frames/opening` · `frames/cut-*`) و`<work>/STYLE_DNA.json` (مسودة).

## ٣. شوف بعينك واكتب الأدلة — إلزامي
- اقرأ `sheet.jpg` (12 لقطة بتوقيتها)، وفريمات الافتتاح، والفريمات حول كل قطع (قبل/بعد 0.12 ث). كاشف القطع يقترح بس — قطع؟ زوم؟ انتقال؟ قناع؟ قرّر من الفريمات.
- لكل ملاحظة مهمة صف بـ`observedInvariants` (أو `adaptiveVariables`/`uncertainTraits`) بنفس حقول الأدلة: `id`، `timecodes` بتوقيت المرجع، `claim` (شنو يصير بالضبط — مو اسم تأثير)، `basis` (observed · measured · inferred)، `confidence` + `reason`، `artifacts`، `trait` (invariant · adaptive · uncertain)، `exceptions`.
- مرجع واحد = اتجاه مبدئي. سمة ما تصير invariant إلا لو تكررت. القصد («يبي يوصّل ثقة») = inferred.
- **الصوت:** ما تگدر تسمع — اسأله شنو يسوي الصوت باللحظات المهمة، أو اكتبه «مجهول».
- عبّي `antiPatterns` (شنو يمسح هالأسلوب) و`applicationLogic` (شلون ينخدم كلامه).

## ٤. حوّلها لمحرّكنا
```bash
python3 "${CLAUDE_SKILL_DIR}/scripts/style_analyze.py" map <work>/STYLE_DNA.json --work <work>
```
| من البصمة | لمحرّكنا |
|---|---|
| إيقاع القطع + الحركة | عائلة بنك الحركات `35_moves.py plan --family calm\|punch\|onetake\|editorial` + `theme.json` ← `pace` |
| ظهور الكابشن (كلمة/قطعة/جملة) ومكانه | `theme.json` ← `capStyle` (`big`/`chunk`/`card`…) و`capStill` · مكان غير تحت ← `window.CAP_Y_AT` (`references/word-fx.md`) |
| المادة والشكل (ورق، زجاج، وثائقي…) | مرشّحات من بنك الستايلات (`references/styles.md`) — أنت تختار بعد ما تشوف الفريمات |
| اللون العام | اقتراح look من `library/looks` — **صفر تعديل لوني على صورته إلا بطلب صريح** |
| ألوان الكروت | الهوية تبقى؛ ألوان المرجع بس إذا طلبها |

وافق؟ `map … --apply` يكتب `capStyle`/`capStill`/`pace` بـ`<work>/theme.json` (نسخة `.bak`). والمشاهد نفسها تتصمّم من البصمة: لكل لحظة مهمة صف «قرار المرجع ← تطبيقه على كلامه» (الحالة الأولى ← الحركة ← الحالة الأخيرة، والمشهد/الحركة من بنكنا).
⚠️ ملف بصمة بجنب قالب ما تغيّر = شغل ناقص — لازم المشاهد والحركات والثيم تتغيّر فعلاً.

## ٥. عيّنة قبل الكل
اختار مقطع 10–20 ث فيه أصعب حركة + انتقال، وارسمه بخطوات video-editor (`04_render_frames.js <work> range <من> <إلى>`) ووريه ورقة لقطات. سجّل بـ`sampleReview`: شنو انفحص (فريمات · تشغيل) + رأيه. يوافق ← كمّل الفيديو. ما عجبه ← غيّر القرار المسيطر بالبصمة، مو زخرفة زيادة.
- `status`: draft ← awaiting-review ← accepted (بس هو يقبل). قبل ما تبدّل بصمة مقبولة انسخها (`STYLE_DNA.json.rev-N`).

## قواعد
- لا تنسخ نص المرجع ولا شعاراته ولا موسيقاه ولا لقطاته. ولا تذكر اسم صانعه بالفيديو.
- المنصات الثلاث بالتساوي — البصمة تنطبق على نسخة إنستقرام ويوتيوب وتيك توك.
- قبل التسليم: `node "${CLAUDE_PLUGIN_ROOT}/engine/arabic-qa.js" <work>` (فحص النص العربي).
