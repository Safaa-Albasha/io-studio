# PNG Exporter — I/O Studio

## الهدف
تحويل سلايدات الكاروسيل من HTML إلى صور PNG عالية الدقة جاهزة للرفع على انستقرام.

## الطريقة المدمجة (الافتراضية)

كاروسيل آي أو استوديو يحتوي بالفعل على زري التصدير:
- **"حفظ هذا السلايد PNG"** — يحفظ السلايد الحالي
- **"تصدير كل السلايدات PNG"** — يحفظ كل السلايدات بالترتيب

هذه الأزرار تعمل عبر مكتبة `html2canvas` بالإعدادات:
```javascript
html2canvas(slide, {
  scale: 2.5,        // جودة عالية
  width: slideWidth,
  height: slideHeight,
  backgroundColor: null,
  useCORS: true
})
```

## إذا طُلب تصدير خارجي

إذا أرسل المستخدم ملف HTML كاروسيل خارجي ويريد تصديره:

1. اقرأ الملف
2. تأكد أن html2canvas موجود، وإلا أضفه
3. تأكد أن أزرار التصدير موجودة، وإلا أضفها
4. احفظ الملف المعدّل وأعطِ المستخدم الرابط

## مواصفات الصورة
- الأبعاد: بنفس قياس الكاروسيل — المفضل 1080×1440 (3:4)، والبديل 1080×1350 لو الكاروسيل مبني عليه
- الجودة: PNG كاملة بدون ضغط
- اسم الملف: `slide-[رقم]-[اسم الحساب].png`


## ⚠️ قاعدتان من التشغيل الفعلي (أغسطس ٢٠٢٦)

### 1) انتظر الخطوط قبل أي تصدير
أي تصدير عبر متصفح خفي لازم يسبقه:
```javascript
await page.evaluate(() => document.fonts.ready);
await new Promise(r => setTimeout(r, 1200));
await page.evaluate(() => document.fonts.ready);
```
بدونها تنكسر حروف عربية عشوائية بالصور المصدَّرة (مربعات/معيّنات)، والنص بالكود سليم —
فتظن إن المشكلة بالنص وتضيع وقتك.

### 2) PNG للأرشيف · JPEG للرفع
- **PNG** للتصدير المحلي والأرشفة (جودة كاملة).
- **JPEG بجودة 0.92** لما ترفع الشرائح لأي خدمة نشر: كاروسيل 10 شرائح PNG ≈ 19 ميقا
  بالطلب الواحد ويفشل من شبكة الجوال؛ نفسه JPEG ≈ 2.6 ميقا. انستقرام يعيد ضغطها أصلاً
  فما فيه فرق بصري.

## 🆕 I/O Studio — التصدير بأمر واحد (بدون فتح المتصفح)
> مبني على png-exporter من content-engine (ماجد الزعابي، بإذنه).
```bash
node "${CLAUDE_PLUGIN_ROOT}/engine/shoot.js" <file.html> --selector .slide --out-dir <dir> [--query size=1080x1920]
```
ينتظر الخطوط (قاعدة 1 فوق)، ويصوّر كل شريحة بمقاسها. للمنصات الثلاث شغّله ثلاث مرات (1080×1440 · 1080×1920 · 1080×1080) — شوف سكل `io-carousel`.
JPEG للرفع: `for f in <dir>/*.png; do ffmpeg -loglevel error -y -i "$f" -q:v 2 "${f%.png}.jpg"; done`
