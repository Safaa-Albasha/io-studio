# حزمة النشر — نفس المحتوى، ثلاث نسخ

## المدخل
المحتوى (سكربت، كاروسيل، فيديو، أو وصف بجملة) + `.io/creator-profile.md` (لهجة، CTA، قيود) + `.io/project.json` (الحسابات).

## المخرج — ملف واحد `output/publish/<slug>.md` بثلاث أقسام بنفس الترتيب دائماً

### إنستقرام
- **الكابشن**: أول سطر هوك (يبين قبل «المزيد»، ≤ 125 حرف) · 2–4 أسطر قيمة · CTA · ≤ 2200 حرف.
- **هاشتاقات**: 3 (مجال واسع + متوسط + محدد).
- **نص الغلاف** ≤ 6 كلمات · **Alt text** وصف للصورة.

### يوتيوب
- **العنوان** ≤ 60 حرف يبين كامل (حد 100) — الكلمة المفتاحية بأوله.
- **الوصف**: سطرين أول بيهم الفكرة · روابط · فصول بالوقت إذا فيديو طويل (`00:00 مقدمة`).
- **هاشتاقات**: 3 (تطلع فوق العنوان). شورت؟ لا تحتاج #shorts.
- **نص الثمبنيل** ≤ 4 كلمات (مو نفس العنوان).

### تيك توك
- **الكابشن**: سطر أو سطرين، أسلوب كلام، سؤال للتعليقات.
- **هاشتاقات**: 3–5 (ترند المجال إذا مناسب + محددة).
- **نص على الفيديو** لأول ثانيتين.

### وقت النشر
إذا بيه `stats.json` (سكل io-dashboard): `node "${CLAUDE_PLUGIN_ROOT}/engine/stats.js" summary --days 90` واستخدم «أفضل يوم/ساعة» لكل منصة. ما بيه؟ گول «جرّب المساء 8–10 بتوقيت جمهورك وراقب».

## افحصها وطلّعها (إلزامي)
اكتب النسخ الثلاث كـ`output/publish/<slug>.json` (الحقول: `title`، `slug`، `cta`، `ad`، واختياري `keyword`/`dm`/`reward`، و`instagram` {caption، hashtags، coverText، altText} · `youtube` {title، description، hashtags، thumbText} · `tiktok` {caption، hashtags، onScreenText}) ثم:
```bash
node "${CLAUDE_PLUGIN_ROOT}/engine/publish-pack.js" check  output/publish/<slug>.json
node "${CLAUDE_PLUGIN_ROOT}/engine/publish-pack.js" render output/publish/<slug>.json --video <الفيديو>
```
### كلمة التعليق ← رسالة خاصة (اختياري)
لما يبي «اكتب كلمة بالتعليقات ويوصلك الرابط بالخاص»: زِد `--keyword` و`--dm` (أو بالملف `keyword` و`dm` و`reward`):
```bash
node "${CLAUDE_PLUGIN_ROOT}/engine/publish-pack.js" render output/publish/<slug>.json --keyword "دليل" --dm "https://…" [--reward "الدليل"]
```
- يضيف لآخر كابشن إنستقرام وتيك توك: `اكتب «دليل» بالتعليقات ويوصلك الرابط بالخاص`، ولوصف يوتيوب: `… والرابط بالتعليق المثبّت` (يوتيوب ما فيه خاص) + `pinnedComment` جاهز. الكلمة تصير `cta` (نفس فحص كرت النهاية).
- يكتب `output/publish/<slug>.dm-reply.txt`: نص الرد التلقائي (ينسخه كما هو) + ملاحظات كل منصة (إنستقرام: حساب احترافي وأداة ردود تلقائية، والرسالة تروح «طلبات الرسائل» لغير المتابعين · تيك توك: الخاص محدود — البديل رد بالتعليق أو الرابط بالبايو · يوتيوب: التعليق المثبّت وأول سطرين بالوصف).
- كرت النهاية بالفيديو: الحركة 242 `commentKeyword` (`FX.commentKeyword(ctx, t, { keyword, reward, platform })`) بنفس الكلمة.
- ما ينربط ولا ينرسل شي تلقائياً — الربط بأداة الرسائل يسويه هو بنفسه.

يوقف لو: منصة ناقصة، الهاشتاق داخل النص، عدد الهاشتاقات فوق المحفوظ، كلمة التعليق (كرت النهاية / `ending.ctaDefault`) مو بالكابشن، منشن لحساب غير حساباته، عنوان يوتيوب > 100، أسلوب «مختصر» > 450 حرف، إعلان بلا إفصاح بأول سطر، أو خطأ نص عربي. الأسلوب من `.io/project.json` ← `writingStyle` (`short` مختصر · `educational` تعليمي · `storytelling` حكاية) وبلهجة كلامه بالفيديو.

## قواعد
- كل منصة نسختها — مو نسخ لصق. نفس الطول من الجهد للثلاث.
- لا هاشتاقات محظورة أو مضللة. إعلان؟ الإفصاح بأول سطر.
- أرقام حسب `numerals`.

## بعدها
نشر أو جدولة ← سكل `io-blotato-publish` (يقرا هالملف، وبموافقة صريحة قبل كل نشر).
