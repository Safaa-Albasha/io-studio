# فحص الجودة

شغّل وكيل **io-quality-manager** (Agent tool، `subagent_type: "io:io-quality-manager"`) وأعطه:
- مسار المخرَج (مجلد PNG، ملف MP4، أو ملف نصي).
- نوعه، والمنصات المقصودة (الافتراضي: الثلاث).

إذا الوكيل مو متوفر، طبّق الدستور بنفسك من `agents/io-quality-manager.md`.

بعد التقرير: اعرض الحواجز 🔴 أول مع الإصلاح المقترح، واسأل: «أصلّحها؟» — لا تصلّح ولا تنشر بدون موافقته.
