# استوديو التسجيل

## ١. جهّز مجلد الدرس
```bash
node "${CLAUDE_PLUGIN_ROOT}/engine/config.js" lesson <slug>
```
`lessons/<slug>/`:
- `slides/` — صور الشرائح (png/jpg…) بالترتيب بالاسم (`p-01.png`…). أو بدالها:
  - عرض HTML (`deck.html`، كل شريحة `<section>` أو `.slide`): صدّره صور:
    `node "${CLAUDE_PLUGIN_ROOT}/engine/shoot.js" lessons/<slug>/deck.html --selector "section, .slide" --out-dir lessons/<slug>/slides --prefix p`
    (أو من الاستوديو نفسه: «📥 استيراد عرض HTML» — أسرع بس الخطوط والصور الخارجية ممكن ما تطلع).
- `prompt.md` — نص الملقّن (سكل io-script يكتبه): أول شريحة `## شريحة العنوان`، والباقي `### شريحة X.Y — عنوان`، وسطر فاضي بين النقاط. هالصيغة يقراها الاستوديوين؛ `## رقم` يشتغل بالسريع بس — استوديو الكورسات يطلع بيه ملقّن فاضي.
- `scene.json` — اختياري، للمشهد المتحرك (سكل io-lesson).
- `theme.json` — ينسخ من `.io/` تلقائياً.

## ٢. شغّل الاستوديو
```bash
node "${CLAUDE_PLUGIN_ROOT}/engine/serve.js"
```
(شغّله بالخلفية.) افتح `http://localhost:4747/studio.html` (أو `/course-studio/studio.html`) بـ **Chrome أو Edge** — الكاميرا والحفظ بالمجلد يحتاجون localhost أو https.

## ٣. علّمه بثلاث أسطر
1. «📂 افتح مجلد الدرس» ← اختار `lessons/<slug>` (اسمح بالتعديل حتى ينحفظ الفيديو بيه).
2. «📷 شغّل الكاميرا والمايك»، واختار المقاس: **عمودي 9:16** (الثلاث منصات) أو **عرضي 16:9** (يوتيوب)، والتوزيع: كاميرا بالزاوية / نص ونص / بدون كاميرا.
3. **R** يسجّل ويوقف · **Space/←** الشريحة التالية · **→** السابقة · **P** إيقاف مؤقت · **M** علامة · **T** الملقّن. «🪟 نافذة منفصلة» يطلع الملقّن بنافذة يحطها قرب الكاميرا.

الناتج: `lessons/<slug>/recordings/<وقت>_<مقاس>.mp4` (أو webm حسب المتصفح) + `*.markers.json` بأوقات تبديل الشرائح والعلامات.

## استوديوين — أيهم؟
| | الاستوديو السريع `studio.html` | استوديو الكورسات `course-studio/studio.html` |
|---|---|---|
| للمين | درس سريع، مشهد متحرك (scene.json)، عمودي للمنصات | محاضرة/كورس طويل، شاشتين، PDF |
| المصادر | صور شرائح · شاشة · مشهد متحرك · عرض HTML | صور شرائح · PDF · شاشة · عرض HTML (يلتقطه من التبويب) |
| الملف | MP4/WebM + markers.json | MP4 عادي (مو مجزّأ) جاهز للمونتاج، ويگدر يحرق نص الملقّن |
| المقاس | 9:16 · 16:9 · 1:1 | 16:9 |
افتراضياً: عمودي أو مشهد → السريع؛ كورس يوتيوب عرضي أو PDF → استوديو الكورسات. دليل استوديو الكورسات: `course-studio/docs.html` (زر 📖 بداخله). استوديو الكورسات يقرا `slides/` أو `deck_frames/` و`prompt.md`/`prompt.txt` من نفس مجلد الدرس.

## ٤. بعد التسجيل
سكل **io-video-cut**: `fix` ← `plan`/`cut` ← `captions`/`burn` ← `variants`. علامات `markers.json` تفيد لو يريد يقص عند شريحة معيّنة.
