# آي أو استوديو — البداية

## نوع الحساب — طبّق الحزمة
اقرأ `accountType` و`contentFormat` من `.io/project.json` وشغّل `node "${CLAUDE_PLUGIN_ROOT}/engine/account-type.js" show` — يطلع لك حزمة النوع (شرائح، حركات، أصوات، لوك، قواعد). وجّه الطلب للسكلات المقترحة بالحزمة أول، وطبّق قواعدها بكل أداة (الطبيب: مصادر علمية + إخلاء مسؤولية إلزامي). بودكاست؟ وجّه لسكل io-podcast-video. ما بيه نوع؟ اسأله سؤال واحد (أو افتح نافذة الترحيب).

## ١. تأكد من الهوية
```bash
node "${CLAUDE_PLUGIN_ROOT}/engine/config.js" check
```
- خطأ «مو موجود» أو «لسه فاضي» → أول رسالة سؤال واحد: **«تكمل الإعدادات من صفحة الويب لو هنا بالشات؟»** وبعدها سكل **io-onboarding** (أ: نافذة الترحيب بـ `serve.js --open welcome.html --reuse` · ب: أسئلة بالشات ← `engine/onboard.js apply`) — الطريقتين يكتبون نفس الملفات، وبيهم سؤال «تريد الترند يومياً؟» والساعة.

## ١.٢ الترند اليومي والطلبات من الصفحات
- `dailyTrends.enabled` بـ `.io/project.json` وتاريخ `.io/trends-last.json` مو اليوم؟ شغّل سكل **io-trends** أول (يكتب الأفكار بالبرنامج)، وبعدها افتح `node "${CLAUDE_PLUGIN_ROOT}/engine/serve.js" --dir "$CLAUDE_PROJECT_DIR" --open "app.html#ideas" --reuse` بالخلفية.
- فتح البرنامج أو استوديو الكورسات أو التايملاين؟ شغّل سكل **io-autopilot** (`queue.js wait` بالخلفية) — أزرار «للمونتاج» و«خلّي Claude يعدّلها» و«سكربت مني» و«أرسل لـ Claude» توصلك منه.
- صالح → اقرأ `.io/creator-profile.md` و`.io/theme.json` و`.io/project.json`.

## ١.٥ اللهجة
احچي ويّا المستخدم باللهجة المحفوظة بـ `.io/project.json` (`dialect`) — مفرداتها بـ `${CLAUDE_PLUGIN_ROOT}/library/dialects/dialects.json`. ما بيه لهجة؟ أول سؤال: «بأي لهجة تحب أحچي وياك؟» (سكل io-onboarding).

## ٣. القاعدة الذهبية — المنصات الثلاث بالتساوي
كل مخرَج يطلع لإنستقرام ويوتيوب وتيك توك سوا (اقرأ سكل `io-platforms` للمقاسات والحدود)، إلا إذا المستخدم حدّد منصة. لا تفضّل منصة على ثانية بالترتيب أو بالجودة.

## الأدوات بالمتصفح
- `node "${CLAUDE_PLUGIN_ROOT}/engine/serve.js" --dir "$CLAUDE_PROJECT_DIR" --open app.html --reuse` ← برنامج آي أو استوديو، استوديو التسجيل (السريع + استوديو الكورسات) ولوحة الإحصائيات على localhost (`--reuse` ما يشغّل سيرفر ثاني إذا واحد شغّال).
- استوديو الكورسات (مفتوح من السيرفر): قبل التسجيل يختار الصيغة (يوتيوب طويل 16:9 / ريلز 9:16 / الاثنين) ويربطه بفكرة؛ بعد «إيقاف» التسجيل ينرفع لـ `recordings/` وطلب مونتاج ينضاف للطابور (سكل io-autopilot).
