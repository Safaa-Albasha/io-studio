# موشن بالكود — قوالب سريعة

**أي محرّك؟**
| الطلب | السكل |
|---|---|
| مقطع قصير 4–10 ث: نص، رقم، رسم، اقتباس، انترو، قبل/بعد | **هذا** (قوالب HTML) |
| فيلم موشن كامل من سكربت، 3D، شرح موقع/تطبيق داخل آيفون، «اشرح لي شلون يشتغل» | **motion-video** (محرّك الفيديو، بنك 100 حركة) |
| درس للأطفال بشخصية تحچي | **lesson** |
| موشن فوق فيديو كلام | **video-editor** |

## نوع الحساب — طبّق الحزمة
اقرأ `accountType` و`contentFormat` من `.io/project.json` وشغّل `node "${CLAUDE_PLUGIN_ROOT}/engine/account-type.js" show` — يطلع لك حزمة النوع (شرائح، حركات، أصوات، لوك، قواعد). اختار القالب والحركات من «حركات الموشن» بالحزمة أول (طبيب: mythFact وheartbeat · رائد أعمال: counter وbarChart وlineChartDraw · مدرّس: qalamWrite وchecklist)، والأصوات من «الأصوات». قواعد الحزمة إلزامية (الطبيب: المصدر وإخلاء المسؤولية يظهرون بالفيديو أو الكابشن).

## الخطوات
1. **اختار القالب** حسب الفكرة (أو ادمج: انترو + kinetic + list بثلاث ملفات، وبعدين وصّلهم — تحت).
2. **انسخ وعدّل:**
   ```bash
   mkdir -p output/motion && cp "${CLAUDE_PLUGIN_ROOT}/templates/motion/<قالب>.html" output/motion/<slug>.html
   ```
   - الألوان والخط: متغيرات `:root` من `.io/theme.json`.
   - النصوص بلهجة البروفايل. الأرقام حسب `numerals`.
   - **⛔ أرقام `stat`/`chart` حقيقية بس** — من المستخدم (مثلاً `stats.js summary`) أو مصدر تكتبه بـ`#src`. القيم بالقالب أمثلة.
   - العقد: `window.__duration` و`window.__seek(t)` — كل حركة محسوبة من t، **ممنوع** setTimeout أو CSS animation/transition. دوال جاهزة: `p()` `outCubic` `inOut` `outBack` `outElastic` `rise()` `pop()` `words()` `fmt()`.
   - المهم داخل المنطقة الآمنة للعمودي: x 140→940، y 220→1440.
3. **لقطات قبل الفيديو:**
   ```bash
   node "${CLAUDE_PLUGIN_ROOT}/engine/render.js" still output/motion/<slug>.html --at 2 --out /tmp/a.png
   ```
   2–3 لقطات، افتحها بـ Read: نص طافح؟ تداخل؟
4. **صدّر:**
   ```bash
   node "${CLAUDE_PLUGIN_ROOT}/engine/render.js" motion output/motion/<slug>.html [--size 1920x1080] [--audio music.mp3]
   ```
5. **توصيل مقاطع** (انترو + محتوى):
   ```bash
   printf "file '%s'\n" a.mp4 b.mp4 > list.txt && ffmpeg -f concat -safe 0 -i list.txt -c copy out.mp4
   ```
6. **شريط الاسم فوق فيديو يوتيوب:**
   ```bash
   ffmpeg -i video.mp4 -i lower.mp4 -filter_complex "[1]colorkey=0x00B140:0.3:0.1[k];[0][k]overlay=enable='between(t,2,7)':eof_action=pass" -c:a copy out.mp4
   ```
