# إعلانات — بيع بدون ما يحس إنه إعلان

**عنده رابط منتج أو اسم منتج معروف؟** شغّل وكيل **io-product-ad-studio** (Agent tool، `subagent_type: "io:io-product-ad-studio"`) — يقرا صفحة المنتج الرسمية بترتيبها، ينزّل مقاطعها وصورها، ويبني كاروسيل إعلاني كل ميزة بشريحة، وينسخه للمنصات الثلاث. هالسكل للإعلان بدون صفحة رسمية (خدمة، منتج محلي، رعاية).

## ١. افهم المنتج (اسأل مرة وحدة باللي ناقص بس)
الاسم · شنو يحل · لمن · السعر/العرض · وين يشتري (رابط، كود خصم) · صور المنتج (مسارها).
إعلان مدفوع أو رعاية؟ لازم إفصاح واضح («إعلان» / «بالتعاون مع») — هذا قانون بأغلب الدول، مو اختيار.

## ٢. ثلاث زوايا، اختار وحدة
- **ألم ← حل**: المشكلة اللي يعرفها الجمهور، بعدين المنتج.
- **قبل/بعد**: النتيجة أول.
- **تجربة شخصية**: «جربته أسبوع، هذا اللي صار».
اعرض الثلاث بسطر لكل وحدة واقترح الأقوى حسب جمهوره.

## ٣. المخرجات — للمنصات الثلاث
1. **سكربت 15–30 ث** (نفس قواعد سكل io-script) — الهوك بأول ثانية، المنتج يبين قبل الثانية 5، CTA وحدة واضحة.
2. **صور إعلانية**: ابنِ HTML بنفس طريقة سكل io-carousel (ألوان `theme.json`، المنتج بطل الصورة، سعر/عرض بخط كبير، الإفصاح ظاهر) وصدّر:
   - إنستقرام 1080×1440 · تيك توك 1080×1920 · يوتيوب 1080×1080 (ونسخة 1280×720 إذا يريد ثمبنيل).
3. **فيديو موشن** من صور المنتج (اختياري) → سكل io-motion: دخول المنتج، 3 مزايا تنكتب، السعر، CTA. 6–12 ثانية.

## ٤. حواجز
- لا وعود صحية/مالية مبالغ بيها، ولا «الأفضل بالعالم» بدون دليل.
- لا شعارات أو علامات تجارية لغير صاحب المنتج.
- قيود البروفايل تنطبق (مثلاً بدون موسيقى).

## ٥. سلّم وافحص
المسارات + السكربت + كابشن لكل منصة (publish-kit). اقترح فحص quality-manager قبل النشر.
